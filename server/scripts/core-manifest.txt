# Classification of every file under src/core/ that also exists in pi-pod's src/.
#
# Paths are relative to src/core/ here and to src/ in a pi-pod checkout.
# scripts/sync-core.sh reads the [shared] paths; scripts/check-core-sync.ts reads
# both sections. Files under src/core/ that appear in neither section are
# server-only — they have no pi-pod counterpart and nothing syncs them.
#
# [shared]  re-vendored verbatim from pi-pod. sync-core.sh overwrites these and
#           refreshes the sha256 column; the checker fails if src/core/ drifts
#           from the recorded hash, and (given a pi-pod checkout) if it drifts
#           from upstream. Do not hand-edit a shared file — change it in pi-pod
#           and re-sync, or move it to [forked] first.
#
# [forked]  a pi-pod file the server has deliberately diverged from. sync-core.sh
#           must never touch these. The checker warns if one becomes byte-identical
#           to pi-pod again, since that means it can probably be promoted.
#
# [pinned]  byte-identical to pi-pod today, but held here because it transitively
#           depends on a [forked] file — re-vendoring it alone could pull in an
#           incompatibility. Promote to [shared] once its dependencies reconcile.
#           Listed separately so the [forked] identity warning stays meaningful.
