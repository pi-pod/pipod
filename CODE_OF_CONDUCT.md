# Code of Conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/)
in every project space: issues, pull requests, discussions, and the hosted service's support
channels.

Report unacceptable behavior privately to the maintainers at support@pipod.dev. Reports are
read only by the maintainers and handled as the Covenant's enforcement guidelines describe.
